# Windows

Download [helloim.ai-Setup.exe](https://github.com/mdalton24/helloim.ai/releases/latest/download/helloim.ai-Setup.exe) from the latest GitHub release, then run it. This is the v1.6.1 installer. Windows may show a SmartScreen prompt because it is unsigned.

The existing published Windows source is in [windows-source](windows-source/), including the Rust backend, UI, and icon tooling. Its existing development version labels are preserved.

The GitHub release includes a SHA-256 checksum to verify the installer.
