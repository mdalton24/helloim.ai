# Linux

helloim.ai offers two Linux downloads on the latest GitHub release: an AppImage (recommended, runs on most distributions) and a Debian package for Debian/Ubuntu.

**AppImage (recommended):** download [helloim.ai-x86_64.AppImage](https://github.com/mdalton24/helloim.ai/releases/latest/download/helloim.ai-x86_64.AppImage), then make it executable and run it:

```sh
chmod +x helloim.ai-x86_64.AppImage
./helloim.ai-x86_64.AppImage
```

**Debian/Ubuntu (.deb):** download [helloim.ai-amd64.deb](https://github.com/mdalton24/helloim.ai/releases/latest/download/helloim.ai-amd64.deb). On an amd64 Ubuntu/Debian system, open a terminal in the download folder and install it with:

```sh
sudo apt install ./helloim.ai-amd64.deb
```

Launch helloim.ai from the applications menu. This package installs the desktop application; it does not install an operating system.

The GitHub release includes a SHA-256 checksum to verify the installer.
